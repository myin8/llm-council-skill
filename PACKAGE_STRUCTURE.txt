Usage
=====

CLI:
  uv run python scripts/run_council.py "Your question" [--stages N] [--models ...]

Agent Skill:
  Ask the council: Your question
  Use $llm-council-skill to compare model perspectives on a topic

Programmatic:
  from council import run_full_council
  result = await run_full_council(user_query="...", models=[...])

Validation
==========

  uv run python test_structure.py
  uv run python scripts/run_council.py --help
